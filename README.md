# Кто ты из учеников Академии?

Production-source VK Mini App проекта «Княжич».

## Текущая версия
Версия 8: 25 канонических результатов, 12 основных вопросов и адаптивные уточнения (не более двух).

Алгоритм v8:
- сравнивает профиль пользователя с 25 двадцатимерными профилями персонажей;
- использует калибровочные поправки, чтобы центральные персонажи не поглощали почти всё пространство ответов;
- считает музыкальный интерес сильным, но мягким сигналом для Илиодора и Евстатия в текущем наборе результатов;
- вызывает уточнение только для реальных кандидатов №1 и №2;
- перед показом уточнения проверяет все варианты ответа и не показывает вопрос, если он не способен изменить победителя;
- не возвращается после уточнений к старому победителю принудительно.

Подробный аудит: `docs/V8_ALGORITHM_AUDIT.md`.

## Интерфейс
- React + TypeScript + Vite + VKUI + VK Bridge.
- Кнопка «Назад» позволяет переиграть предыдущий ответ.
- Счётчик 1/12…12/12; адаптивные вопросы помечаются «12/12 · уточнение».
- Результат показывает портрет и карточку персонажа.
- «Похвастаться результатом» открывает выбор:
  - «Поделиться в истории» — вертикальная карточка из `public/share/`;
  - «Опубликовать на странице» — квадратная карточка из `public/share/wall/`.
- «Позвать друга в Академию» использует VK Invite Box с fallback-механизмами.
- Сессия прохождения хранится в `sessionStorage`.

## Ассеты
Ожидаемая production-комплектация:
- 25 портретов — `public/assets/characters/`;
- фон Академии — `public/assets/academy.webp`;
- 25 Story-карточек — `public/share/*.webp`;
- 25 квадратных wall-карточек — `public/share/wall/*.webp`.

## Запуск
```bash
npm install
npm run dev
```

Проверки и сборка:
```bash
npm run test:engine
npm run audit:distribution
npm run build
npm run preview
```

CI на каждом push в `main` выполняет установку зависимостей, smoke-test движка, аудит распределения и production build.

## VK App ID
После создания Mini App необходимо заменить `app_id: 0` в `vk-hosting-config.json` реальным ID приложения, проверить VK Bridge внутри VK и только затем выполнять production deploy.

Для деплоя используется официальный пакет `@vkontakte/vk-miniapps-deploy`.

## Данные
Production-данные разделены на:
- `src/data/split/meta.json`;
- `profiles-1.json` … `profiles-5.json`;
- `questions.json`;
- `tiebreakers.json`.

`src/data/index.ts` собирает их в единый `QuizData`.
