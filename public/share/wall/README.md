# Wall share cards

Сюда загружаются 25 квадратных карточек 1:1 для публикации результата на странице / стене VK.

Имена файлов должны совпадать с именами story-карточек из `public/share/`, например:

- `olesha.webp`
- `sanko.webp`
- `yarko.webp`
- `ruman.webp`

Не переименовывать: версия 7 приложения обращается к этим файлам по пути `/share/wall/<имя>.webp`.
